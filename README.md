# Gooner's Polygon Alpha

Откройте project.godot в Godot 4.7.1 и нажмите F5. Хост создаёт комнату, копирует шестизначный код и сообщает его друзьям. В одной локальной сети введите код и нажмите «Присоединиться». Поиск использует широковещательный IPv4 UDP на порту 24568. Игровое соединение использует порт хоста, по умолчанию UDP 24567. В разных сетях доступен прямой вход по достижимому IP хоста.

Когда в комнате от 2 до 6 игроков и все участники готовы, хост открывает арену. WASD — ходьба, удерживайте Shift для бега, Space — прыжок. Соберитесь в группу: расстояние между любой парой игроков должно быть не больше 4,5 м. Если группа разойдётся, подтверждения сбросятся. Нажмите E для согласия на сборку или повторно для отмены. После согласия всей команды появляется цепочка, и Space поднимает сторону следующего игрока. X у любого участника разрывает цепочку у всех. Esc — выход. Локальная тренировка доступна в главном меню.

В цепочке удерживайте A для поворота влево или D для поворота вправо. Встречные голоса вычитаются. Первый голос перевеса даёт 35°/с, каждый следующий добавляет 10°/с до предела 75°/с. Разгон с места занимает 0,2 с, торможение — до 0,08 с. Голубая дуга над группой показывает направление и скорость поворота.
